# iCalendar (.ics)

Hand-rolled `Z` timestamps on naive local times are the default agent bug.
Generate with a library (or `scripts/write_event.py`), then parse the bytes
back. Do not start from a raw `BEGIN:VCALENDAR` skeleton.

## Related skills

| Need | Skill |
|------|-------|
| HTML email that attaches this invite | `email-html` |
| Timezone-aware analysis of event logs | `data-analysis` |

## Workflow

1. Confirm local time, **IANA timezone**, duration, organizer, attendees, recurrence.
2. If a bare clock time has no zone and the instant matters, **ask**. Do not guess.
3. Generate with `icalendar` or `scripts/write_event.py`. Stable UID. SEQUENCE starts at 0.
4. Parse the generated bytes. Check DTSTART/DTEND instant, UID, METHOD, SEQUENCE.
5. Updates/cancels: same UID, same organizer, incremented SEQUENCE.

**Hard rules**
- Never emit a naive datetime with a `Z` suffix.
- UID is globally unique and **stable** across updates. Changing it creates a duplicate.
- All-day `DTEND` is exclusive (July 4 holiday → end July 5).
- `METHOD:REQUEST` for invites with attendees; `PUBLISH` for a public calendar; `CANCEL` to cancel.
- Recurring *local* events need a named `TZID` and a `VTIMEZONE` (the library emits this if you pass a `ZoneInfo`). UTC `Z` is for single instants, not "every Monday at 9 in New York."

---

## Time representation

| Kind | Write |
|------|--------|
| Single meeting, known zone | `ZoneInfo("America/New_York")` datetimes — library may emit `TZID` or UTC |
| Single meeting, "just store UTC" | aware UTC datetimes → `Z` |
| All-day | `date` start + exclusive `date` end, **no** time, **no** `Z` |
| Recurring local | `TZID=America/New_York` + `VTIMEZONE`. Not UTC. DST would shift the wall clock. |
| Floating (rare) | no `Z`, no `TZID` — only when the user wants "9:00 wherever you are" |

## Generate

```bash
pip install icalendar
python ics/scripts/write_event.py \
  --summary "Design review" \
  --start "2026-03-20T11:00:00" \
  --tz America/New_York \
  --minutes 60 \
  --method REQUEST \
  --organizer "mailto:pm@acme.com" \
  --attendee "mailto:ada@acme.com" \
  --out meeting.ics
```

```python
from datetime import datetime, timedelta
from zoneinfo import ZoneInfo
from icalendar import Calendar, Event, vCalAddress, vText
import uuid

cal = Calendar()
cal.add("prodid", "-//Acme//Meetings//EN")
cal.add("version", "2.0")
cal.add("method", "REQUEST")

tz = ZoneInfo("America/New_York")
start = datetime(2026, 3, 20, 11, 0, tzinfo=tz)
end = start + timedelta(hours=1)

ev = Event()
ev.add("uid", f"{uuid.uuid4()}@acme.com")
ev.add("dtstamp", datetime.now(tz=ZoneInfo("UTC")))
ev.add("dtstart", start)
ev.add("dtend", end)
ev.add("summary", "Design review")
ev.add("description", "Agenda:\n1. Goals\n2. Mockups")
ev.add("location", "https://zoom.us/j/123")
ev.add("status", "CONFIRMED")
ev.add("sequence", 0)

organizer = vCalAddress("MAILTO:pm@acme.com")
organizer.params["cn"] = vText("Pat Manager")
organizer.params["role"] = vText("CHAIR")
ev["organizer"] = organizer

attendee = vCalAddress("MAILTO:ada@acme.com")
attendee.params["cn"] = vText("Ada")
attendee.params["ROLE"] = vText("REQ-PARTICIPANT")
attendee.params["RSVP"] = vText("TRUE")
ev.add("attendee", attendee, encode=0)

cal.add_component(ev)
open("meeting.ics", "wb").write(cal.to_ical())
```

The library folds lines at 75 octets, uses `CRLF`, and escapes `DESCRIPTION`. Do not re-fold by hand.

### All-day

```python
from datetime import date
ev.add("dtstart", date(2026, 7, 4))
ev.add("dtend", date(2026, 7, 5))  # exclusive
```

### Recurrence

```python
ev.add("rrule", {"freq": "weekly", "byday": ["MO", "WE"], "count": 10})
```

`byday` is a **list** of uppercase `MO`/`TU`/`WE`/`TH`/`FR`/`SA`/`SU`. Do not pass `"mo,we"`.

### Update / cancel

```python
ev.add("sequence", 1)          # was 0; same UID
cal["method"] = "CANCEL"
ev.add("status", "CANCELLED")
```

## Parse and verify

```python
from icalendar import Calendar
cal = Calendar.from_ical(Path("meeting.ics").read_bytes())
for component in cal.walk():
    if component.name == "VEVENT":
        print(component.get("uid"), component.get("dtstart").dt, component.get("sequence"))
```

```text
[ ] Parsed DTSTART instant matches the intended local time
[ ] All-day end is exclusive
[ ] UID stable; SEQUENCE incremented on update
[ ] REQUEST has organizer + attendees
[ ] Recurring local event has TZID/VTIMEZONE, not Z
[ ] Imported into at least one client when available
```

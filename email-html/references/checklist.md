# Email QA Checklist

- [ ] Subject + preheader set
- [ ] Plain-text alternative matches HTML
- [ ] Single primary CTA; URL is absolute HTTPS
- [ ] Images have alt text; logo ≤ ~600px wide
- [ ] Footer: identity, unsubscribe (marketing), address if required
- [ ] Personalization tokens have fallbacks
- [ ] Renders at 320px width without horizontal scroll
- [ ] Dark mode: text still readable
- [ ] No JS, no external fonts required for core message
- [ ] Test send to at least one real inbox
